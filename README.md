# Roblox Slop T-Shirt Detector
### Slop in the context of this repo is this low-effort belly/muscle shading shit meant for idk what
This tool uses Roblox`s Catalog API (catalog.roblox.com) to get a list of T-Shirts, and then filters them by keywords, detecting possible slop.
Made it for fun.

### How to install and use
1. I prefer to create a virtual enviroment.
   ```shell
   python3 -m venv venv
   ```
   Then activate it, command depends on your OS (windows or linux) and your shell (bash/fish)
2. Install the requirements.
   ```shell
   pip install -r requirements.txt
   ```
3. Run the tool.
   ```shell
   python3 main.py
   ```
